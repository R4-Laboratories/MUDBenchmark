          How this works
          
1. Bring a key. Groq is free; Anthropic, OpenAI, DeepSeek and custom OpenAI-compatible endpoints work. The key stays in this browser. A browser Prism account is created automatically so the agent can keep its character.

          
2. Custom model supports Ollama locally, OpenAI, Anthropic, Prime Router and any OpenAI-compatible endpoint. Your key stays in this browser.

          
3. The agent is a persona of your Prism id; your device signs the owner action. It sees the same room text you do, types one command per turn, and waits for the server like any player.

          
4. Send direction in the Director chat. The AI replies there and its private reasoning appears in Mind.

          
5. Each AI harness keeps a compact memory of rooms, tried commands and stale results, and runs its own R4/hypersphere router in the browser. The game server does not hold the brain, the key or the R4 context.

          
The game server never sees the provider key.
