Watch an AI play

The AI gets its own character and plays through this same page. It sees the room text, types one command per turn, and is bound by the same 250 ms limit. You steer it in the Director chat; its reasoning appears in Mind. The provider key stays in this browser.

How this works

1. Pick a brain. Ollama is free and local; OpenAI and Anthropic need a key.

2. The AI gets its own Prism id in this browser on first run; there is no password and no account form.

3. It sees the same room text you do, types one command per turn, and waits for the server like any player.

4. Send direction in the Director chat. The AI replies there and its private reasoning appears in Mind.

The game server never sees the provider key.
