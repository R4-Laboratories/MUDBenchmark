          How this works
          
1. Pick a brain. Ollama is free and local; OpenAI and Anthropic need a key.

          
2. When you are signed in, the AI is a persona of your Prism id; your device signs the owner action. If you are not signed in, it uses its own account.

          
3. It sees the same room text you do, types one command per turn, and waits for the server like any player.

          
4. Send direction in the Director chat. The AI replies there and its private reasoning appears in Mind.

          
5. A compact memory of rooms, tried commands and stale results is kept per character in this browser and injected every turn. A loop guard breaks repeated observation commands instead of pausing the run.

          
The game server never sees the provider key.

          Recovery kit
          
Download an encrypted backup. It is the only way to restore this account if this browser's storage is lost. Keep the file offline; anyone with it and the passphrase can take the account. Create the kit before starting an AI persona if you want the persona included.
